# Releases

Versioning follows [Semantic Versioning](https://semver.org/). Release notes use the [Keep a Changelog](https://keepachangelog.com/) categories (Added, Changed, Fixed, Removed, Security).

- **0.x.y**: pre-launch. **1.0.0** = public launch on the real domain.
- **Minor** (0.3.0 → 0.4.0): new section, new feature, visual/design change, new assets.
- **Patch** (0.3.0 → 0.3.1): bug fix, copy/text fix, small style tweak.
- Every release has an annotated git tag (`vX.Y.Z`), and `package.json` `version` matches the latest release.
