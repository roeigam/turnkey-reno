# Stock image credits

Every stock image in this folder needs an entry here **before it goes on the site**. Use only images whose license allows commercial use on a business website. Keep the license page or receipt (Adobe Stock) with the client's records.

Copy the template below for each image.

## Template

```
### <file name, e.g. how-we-work-kitchen.jpg>
- Used for:      <section, e.g. How We Work side image (howWeWork.image)>
- Source URL:    <the image's page on the stock site>
- Photographer:  <name / profile>
- License:       <Unsplash License | Pexels License | Adobe Stock Standard/Extended (license ID)>
- Downloaded:    <YYYY-MM-DD>
- Notes:         <attribution requirements, edits made (crop/resize), model/property release if relevant>
```
